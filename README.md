## ✨ 훈녀 깃 꿀팁 대방출 ✨

> 💡 이것만 알아도 깃 고수 소리 듣는다능 (｡•̀ᴗ-)✧

```bash
git status          # 🔍 지금 내 상태 확인하기 (거울 보듯이♡)
git add .           # 🛍️ 바뀐 거 장바구니에 담기
git commit -m "메시지"  # 📸 셀카 찍듯이 기록 남기기
git push            # 🚀 깃허브에 업로드! 인스타 올리듯이~
git pull            # 📥 최신 소식 받아오기
```

## 🎀 훈녀 생활 수칙 🎀

- [x] 커밋 메시지는 예쁘고 알아보기 쉽게 쓰기 💅
- [x] 자주자주 커밋하기 (일기 쓰듯이!) 📔
- [ ] `git push --force`는 함부로 쓰지 않기 (위험해요 훈녀들 ⚠️)
- [ ] 매일매일 잔디 심기 🌱🌱🌱
